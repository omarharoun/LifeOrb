# LifeOrb Setup Guide

## Prerequisites
Make sure you have the following installed:
- **Node.js** (version 18 or higher) - [Download here](https://nodejs.org/)
- **npm** or **yarn** package manager

## Installation Steps

1. **Navigate to the project directory:**
   ```bash
   cd LifeOrb
   ```

2. **Install dependencies:**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. **Open your browser:**
   Navigate to `http://localhost:3000` to see the LifeOrb platform

## Design Improvements Made

### 🎨 **Visual Comfort Enhancements**
- **Warmer Color Palette**: Replaced cold blues with warm oranges, sage greens, and soft roses
- **Comforting Background**: Multi-layered gradients with floating orb decorations
- **Softer Shadows**: Glass-morphism effects with gentle depth
- **Rounded Corners**: More organic, friendly button and card shapes

### 🌟 **Interactive Elements**
- **Enhanced Orb Animation**: Larger central orb with glow effects and floating particles
- **Smooth Transitions**: 300-500ms duration for calm, unhurried interactions
- **Breathing Animations**: Subtle scale effects that feel organic and alive
- **Gentle Hover States**: Cards lift and glow softly on interaction

### 📝 **Typography & Content**
- **Poppins Font**: Friendlier, more approachable typeface
- **Compassionate Language**: Nurturing, supportive copy throughout
- **Better Hierarchy**: Larger headings with improved spacing
- **Meaningful Icons**: Plant 🌱, Sparkles ✨, Handshake 🤝 for warmth

### 🎯 **User Experience**
- **Comfortable Forms**: Softer input fields with better focus states
- **Accessible Design**: High contrast with comfortable reading sizes
- **Progressive Disclosure**: Information revealed gently and naturally
- **Mobile-First**: Responsive design that works beautifully on all devices

## Technology Stack
- **Next.js 14** with App Router
- **React 18** with TypeScript
- **Tailwind CSS** with custom design system
- **Framer Motion** for smooth animations
- **Custom Color Palette** for comforting aesthetics

## Development Notes
- All components use TypeScript for better development experience
- Custom CSS classes defined in `globals.css` for consistent styling
- Responsive design implemented with Tailwind's mobile-first approach
- Smooth animations prioritize user comfort over flashiness

## Viewing the Changes
Once you run `npm run dev`, you'll see:
- A warmer, more inviting homepage with soft gradients
- Floating decorative orbs in the background
- A larger, more prominent central LifeOrb with glow effects
- Softer, more rounded buttons and cards
- Gentle animations that breathe with life
- Compassionate, nurturing copy throughout

The overall feeling should be one of warmth, safety, and invitation - like entering a comfortable space where you can openly explore your life's possibilities.
